# AI vs Human Feedback Analysis - Data and Analysis Repository

This repository contains the complete analysis code for the research paper "Comparison of Feedback from AI and Supervisors" by Takeshi Kondo.

## Purpose

This repository is designed for researchers who have read our paper and wish to:
- Review and verify the statistical analysis methods
- Reproduce the analysis results
- Explore the analysis code in detail
- Build upon our work for further research

## Repository Structure

```
.
├── data/
│   ├── raw_data.csv              # (Not committed - contains personal information)
│   ├── raw_conversion_table.csv  # (Not committed - contains personal information)
│   ├── data.csv                   # Processed tidy dataset
│   └── data_feedback_text.csv    # Feedback text data

├── renv.lock                      # R package dependencies (exact versions)

```

**Note**: Raw data files (`raw_data.csv`, `raw_conversion_table.csv`) contain personal information and are not included in this repository. Processed, de-identified data files are provided.

## Reproducing the Analysis

### Using Dev Container (Recommended)

The easiest way to reproduce the analysis is using the included Dev Container, which provides a complete reproducible environment.

**Requirements:**
- Docker
- Visual Studio Code with Dev Containers extension

**Steps:**

1. Clone this repository and open in VS Code:
   ```bash
   git clone <repository-url>
   cd ai-vs-human-feedback-analysis
   code .
   ```

2. When prompted, click "Reopen in Container" (or use Command Palette: "Dev Containers: Reopen in Container")

3. Wait for the container to build and initialize (see [.devcontainer/postCreateCommand.sh](.devcontainer/postCreateCommand.sh) for initialization details)

4. Render the analysis:
   ```bash
   quarto render src/ai_vs_human.qmd
   ```

### Local Installation (Alternative)

For local installation, refer to [.devcontainer/postCreateCommand.sh](.devcontainer/postCreateCommand.sh) for the initialization steps, which include:
- Installing R packages via renv
- Installing Python packages via uv

Then render the analysis with:
```bash
quarto render src/ai_vs_human.qmd
```

## Analysis Document

The main analysis is in [ai_vs_human.qmd](src/ai_vs_human.qmd), which contains:

1. Data description and summary statistics
2. Feedback length comparison (paired t-tests)
3. Feedback score comparison across 5 criteria (paired t-tests with Bonferroni correction)
4. Ordinal logistic regression analysis (CLMM with mixed effects)
5. Correlation analysis between feedback length and scores
6. Consistency analysis (variance comparison)

Running `quarto render` will:
- Generate an HTML report with all results
- Save statistical outputs to the `result/` directory (CSV files and figures)

## Software Environment

The development container ensures reproducibility with locked dependency versions:

- **R**: Version 4.3.x with packages in `renv.lock`
- **Python**: Version 3.11.x with packages in `pyproject.toml`
- **Quarto**: Latest stable version

See [.devcontainer/Dockerfile](.devcontainer/Dockerfile) for complete environment details.
